1. Introduction

This internship developed and documented an integration between the AgWise seasonal climate-forecast pipeline, DSSAT, and IWMI water-context products. The work made the Chókwè workflow reproducible, exposed ranked DSSAT treatments through an advisory payload, and tested how IWMI rainfall could complement the precipitation input.

Main target approach. The preferred operational solution is to integrate validated IWMI daily observations into the AgWise observation/reference layer. This is not yet complete because IWMI daily observations and their metadata are still pending. A synthetic monthly-to-daily experiment was implemented as an interim bridge.

2. Implemented workflow

Chókwè configuration: 2025-11-01 to 2026-02-28; one-month lead; maize cultivar ID 900111; manual extent -23.5, 32.5, -25.5, 33.5.

3. Methodology

AgWise uses forecast, hindcast, and historical reference data to learn systematic model errors, then produces corrected daily PRCP, TMAX, TMIN, and SRAD fields for DSSAT. IWMI context is retained with provenance and does not silently rerank treatments.

Interim rainfall experiment: synthetic IWMI rainfall replaces only PRCP at the DSSAT handoff; corrected AgWise temperature and solar radiation remain in use.

4. Three integration approaches

ApproachPurposeStatus and interpretation
1. Contextual advisoryShow rainfall anomaly, ET, irrigation probability, and water stress.Implemented. Context is qualified and does not change DSSAT ranking.
2. Synthetic PRCPTest DSSAT sensitivity to IWMI monthly rainfall.Implemented as interim. Synthetic daily values; not observations.
3. Daily observationsIntegrate validated IWMI daily data into AgWise reference/validation.Main target; pending IWMI. Preferred operational approach.
Why Approach 3 is preferred: daily observations preserve actual wet-day timing and support measurement of bias, wet-day frequency, dry spells, extremes, and forecast skill. The current monthly export cannot recover those properties.

5. IWMI monthly-to-daily synthesis

The Digital Twins rainfall analysis export contains 309 monthly values from 2001-01 through 2026-09. It is not a daily observational dataset (daily_observations: false). For each month, exact target-year totals were used for the 2025/26 season; no climatology fallback was needed.

8. Deliverables

  • Reproducible Chókwè YAML use case and Windows-safe execution.
  • DSSAT handoff with optional PRCP override and checkpoints.
  • Normalized advisory schema and Chókwè example.
  • IWMI STAC/context adapter with provenance and warnings.
  • Monthly IWMI exporter and 2001–09/2026 source.
  • Target-year synthesis modes and metadata sidecars.
  • Comparison workflow and integration tests.
  • Setup, Makefile, and scientific-limitations documentation.

9. Limitations

  • Synthetic rainfall does not recover observed wet-day timing, storm persistence, extremes, spatial variation, or rainfall–temperature dependence.
  • The advisory represents one season, one generic soil setup, and limited cultivar coverage.
  • The IWMI station identifier returned by the API differs from the requested identifier and requires provider confirmation.
  • No operational claim should be made until daily observations and multi-season validation are available.

10. Recommended handover plan

  1. Obtain IWMI daily observations with units, timestamps, coordinates, quality flags, and missing-value rules.
  2. Compare them with the AgWise reference over the common historical period, ideally 1994–2016.
  3. Assess bias, wet-day frequency, dry spells, extremes, and seasonal totals; then integrate the validated series into AgWise.
  4. Repeat matched-cell baseline/IWMI tests across multiple seasons before operational advisory use.
Conclusion. The internship delivered a working, transparent integration prototype. The synthetic experiment demonstrates the interim interface; the preferred final solution is validated IWMI daily observations integrated into AgWise.
